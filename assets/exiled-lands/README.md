# Exiled Lands Asset Layout

Use the folders below when preparing round content.

- `screenshots/`: one image per playable location
- `screenshots/references/`: optional map pin reference captures
- `map/`: the single Exiled Lands base map image used for guesses

Recommended naming:

- Screenshots: `el-001.png`, `el-002.png`, ...
- Map: `exiled-lands-basemap.png`

Coordinate convention for answers:

- `x` and `y` are normalized values in `0..1`
- `x = 0` is the left edge, `x = 1` is the right edge
- `y = 0` is the top edge, `y = 1` is the bottom edge
